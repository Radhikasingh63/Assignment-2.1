1. HTML Code — index.html

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">

    <!-- Page title -->
    <title>My First Webpage</title>
</head>
<body>
    <!-- Main heading -->
    <h1>Welcome to My First Webpage</h1>

    <!-- About me section -->
    <h2>About Me</h2>
    <p>Hello! My name is Harsh Patel. I am a BTech CSE student.</p>

    <!-- Education section -->
    <h2>My Education</h2>
    <p>I am learning computer science and web development.</p>

    <!-- Hobbies section -->
    <h2>My Hobbies</h2>
    <p>I enjoy reading books and exploring new things.</p>

    <!-- Learning goals section -->
    <h2>My Learning Goals</h2>
    <p>I want to learn HTML, CSS, JavaScript, and programming.</p>
</body>
</html>



2. How to run it in VS Code
1. Open VS Code and create a file named index.html.
2. Paste the HTML code above.
3. Press Ctrl + S to save the file.
4. Open the folder where you saved the file.
5. Double-click index.html to open it in Chrome or another browser.
6. Take a screenshot of the webpage using Win + Shift + S.
